# Aetheris Support Guide

Welcome to Aetheris support. If you need assistance building or using `.aeth` applications, use the resources below.

## Getting Help
- **Documentation**: Read `README.md`, `SPECIFICATION.md`, and `ARCHITECTURE.md`.
- **Bug Reports**: Open an issue detailing compiler diagnostic errors, line coordinates, and code snippets.
- **Q&A Discussions**: Participate in GitHub Discussions for questions regarding language ergonomics.
