# Aetheris Model Conversion & ONNX Specification (v1.0)

This document defines how external machine learning models (ONNX, safetensors, GGUF) are imported into Aetheris and compiled as native `neural` modules, and how Aetheris models are exported.

---

## 1. Workflow

```
 model.onnx ──► Import ──► Graph IR ──► Optimize ──► Quantize (opt.) ──► Emit
                                                                          │
                                       neural module (.aeth) + weights (.apk)
                                       compiled via --target=ai / native / web
```

```bash
aeth model import classifier.onnx -o models/classifier.aeth
aeth model import llm.gguf --quant=q4 -o models/llm.aeth
aeth model export models/classifier.aeth --format=onnx -o out.onnx
```

---

## 2. Supported Formats

| Format | Import | Export | Notes |
| :--- | :--- | :--- | :--- |
| ONNX (opset 13–21) | Yes | Yes | Primary interchange |
| safetensors | Weights only | Weights only | Pair with a `neural` definition |
| GGUF | Yes | No | LLM inference with quantized weights |
| TFLite | Yes | No | Mobile and microcontroller models |
| `.apk` (Aetheris weight pack) | Yes | Yes | Native, memory-mappable, compressed |

---

## 3. Generated Code

Importing produces a readable `neural` declaration and a weight asset:

```aeth
// generated by `aeth model import`
neural Classifier ~
    input(shape: [1, 512], dtype: f32) ~
    layer Dense(inputs: 512, outputs: 256, activation: "relu") ~
    layer Dense(inputs: 256, outputs: 64,  activation: "relu") ~
    layer Dense(inputs: 64,  outputs: 2,   activation: "softmax") ~
    weights asset("classifier.apk") ~
end
```

Usage:

```aeth
fn classify(emb: tensor[f32]) -> Result[tensor[f32], text] ~
    return infer Classifier with emb ~
end
```

## 4. Operator Coverage

| Category | ONNX Operators |
| :--- | :--- |
| Linear | `Gemm`, `MatMul`, `Add`, `Mul` |
| Convolution | `Conv`, `ConvTranspose`, `MaxPool`, `AveragePool`, `GlobalAveragePool` |
| Activation | `Relu`, `Sigmoid`, `Tanh`, `Softmax`, `Gelu`, `LeakyRelu` |
| Normalization | `BatchNormalization`, `LayerNormalization` |
| Tensor | `Reshape`, `Transpose`, `Concat`, `Slice`, `Gather`, `Squeeze` |
| Sequence/Attention | `Attention`, `LSTM`, `GRU` |

Unsupported operators produce error `M401` listing each node and its location in the graph. Custom operators may be provided by implementing a `kernel fn` and registering it:

```aeth
@onnx_op("com.example::Swish")
kernel fn swish(x: *const f32, out: *mut f32, n: u32) ~ ... end
```

---

## 5. Graph Optimization

| Pass | Effect |
| :--- | :--- |
| Constant folding | Precompute static subgraphs |
| Operator fusion | Conv+BN+ReLU, MatMul+Bias+Activation |
| Layout selection | NCHW vs NHWC per backend |
| Dead node removal | Drops unused outputs |
| Shape specialization | Bakes static shapes; dynamic dims supported via `symbolic` markers |

`--report-graph` prints before/after node counts.

---

## 6. Quantization

| Mode | Flag | Description |
| :--- | :--- | :--- |
| FP16 / BF16 | `--precision=f16` | Half-precision weights and compute |
| INT8 | `--quant=int8 --calib=data/` | Post-training static quantization with calibration data |
| 4-bit | `--quant=q4` | Group-wise weight quantization (LLMs) |

The compiler reports accuracy deltas on a supplied validation set (`--validate=val.csv`) and refuses to emit if error exceeds `--max-drop` (default 1%).

---

## 7. Target Notes

* **Microcontrollers (`native-32`)**: INT8 models compile to static-arena inference with no heap; peak activation memory is computed at compile time and reported (`--report-memory`).
* **Web**: Weights stream as compressed chunks; inference uses WebGPU with WASM SIMD fallback.
* **GPU**: See `GPU_NATIVE_EMISSION.md` for kernel generation.

## 8. Weight Pack Format (`.apk`)

Header with magic `AWPK`, tensor index (name, dtype, shape, offset), then aligned (64-byte) tensor data, optionally Zstd-compressed per tensor. Files are memory-mappable with zero copy on native targets and carry a SHA-256 checksum verified at load.

## 9. Licensing Reminder

Imported models retain their original licenses; `aeth model import` records provenance in the generated file header.
